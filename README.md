# ClipManagerForWindows

A simple clipboard manager for Windows, inspired by CopyClip for macOS.

![Demo](media/demo.gif)

## Features

*   **System Tray Icon**: Access all features from the system tray.
    *   Right-click to show recent snippets, clear history, open preferences, or quit the application.
    *   Click on a snippet to copy it to the clipboard.
*   **Global Hotkey**: Use a global hotkey (default `Ctrl+Shift+V`) to open a history window with search and full keyboard navigation.
*   **Clipboard History**:
    *   Captures and stores text from the clipboard.
    *   Persists history across restarts.
    *   Clear all history at once.
*   **Settings**:
    *   Configure the number of entries to store.
    *   Adjust the history depth and retention days.
    *   Toggle "launch on startup".
    *   Customize the global hotkey.
    *   Set up an ignore list for sensitive applications.
    *   Choose between light, dark, or system theme.
